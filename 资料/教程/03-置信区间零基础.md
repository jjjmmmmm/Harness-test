# 教程 03 · 置信区间零基础（D2 Block 3 配套）

> 目标：JD 必须项里最陌生的一条——"理解置信区间，能判断'这个差异有没有可能是运气'"。读完你能亲手算出 JD 那句"通过率只差 0–8pp（置信区间含 0）"是什么意思，并把它变成你报告里的标配。
> 需要：比例、加减乘除、开方（Python 帮你开）。不需要任何统计学基础。

---

## 1. 为什么点估计不够

你跑实验：A 配置 8 题过了 6 题（75%），B 配置过了 4 题（50%）。差 25pp，A 好——**能下这个结论吗？**

不能，因为你看到的是**样本**，不是真相。同一对配置重跑一遍，可能就是 5/8 vs 5/8。样本越小、差异越小，"这个差异是运气"的可能性越大。

**置信区间（CI）就是给点估计配的"误差条"**：基于这次样本，算出一个区间，意思是"如果运气因素都有，真实差异大概率落在这个范围里"。

## 2. 唯一需要的公式（两比例之差的 95% CI）

两个配置各跑 n 次，A 过了 x 次，B 过了 y 次：

```
p1 = x/n          （A 的通过率）
p2 = y/n          （B 的通过率）
diff = p1 - p2    （点估计）

SE = sqrt( p1(1-p1)/n + p2(1-p2)/n )     （标准误差：差异的"典型抖动量"）

95% CI ≈ diff ± 1.96 × SE
```

判读（就三条，背下来）：

| 情形 | 结论 |
| :--- | :--- |
| 区间**不含 0** | 差异大概率是真的 → 可以说"配置 A 更好"（附上区间） |
| 区间**含 0** | 差异可能只是运气 → 只能说"未发现可区分的证据" |
| 区间太宽 | 不是没差异，是**样本太少** → 加样本重跑，而不是硬下结论 |

**1.96 是什么**：正态分布下覆盖中间 95% 概率的倍数。记住 1.96 ≈ 2 就够用。

## 3. 亲手算一遍 JD 的例子

JD 说"通过率只差 0–8pp（置信区间含 0）"。设两组各 n=200 次，A 过 60%（120 次），B 过 55%（110 次）：

```
diff = 0.05（5pp）
SE = sqrt( 0.6×0.4/200 + 0.55×0.45/200 ) = sqrt(0.0012 + 0.0012375) ≈ 0.0494
95% CI = 0.05 ± 1.96×0.0494 = 0.05 ± 0.0968 = [-4.7pp, +14.7pp]
```

**区间横跨 0**——尽管点估计是 +5pp，你**不能**说"B 更差"，因为运气完全可能造成这 5pp。这就是"光看跑分分不清"的数学含义。

## 4. stats.py：公式版 + 自助法交叉验证

```python
import math
import random

def ci_two_props(x1: int, n1: int, x2: int, n2: int):
    """两组通过次数/总数 → (差值, 95%CI下限, 95%CI上限)，Wald 正态近似。"""
    p1, p2 = x1 / n1, x2 / n2
    diff = p1 - p2
    se = math.sqrt(p1 * (1 - p1) / n1 + p2 * (1 - p2) / n2)
    return diff, diff - 1.96 * se, diff + 1.96 * se

def ci_bootstrap(a_pass: list, b_pass: list, trials: int = 10000):
    """自助法：把两组各自重抽样一万次，看差异的分布。
    a_pass/b_pass 是 0/1 列表，如 [1,1,0,1,...]。
    它不依赖公式假设，用来交叉验证公式结果。"""
    diffs = []
    for _ in range(trials):
        ra = [random.choice(a_pass) for _ in range(len(a_pass))]
        rb = [random.choice(b_pass) for _ in range(len(b_pass))]
        diffs.append(sum(ra) / len(ra) - sum(rb) / len(rb))
    diffs.sort()
    lo = diffs[int(0.025 * trials)]
    hi = diffs[int(0.975 * trials)]
    return sum(diffs) / trials, lo, hi

if __name__ == "__main__":
    # 例题：A 配置 12/20 过，B 配置 9/20 过
    d, lo, hi = ci_two_props(12, 20, 9, 20)
    print(f"公式版: 差={d:+.1%}, 95% CI=[{lo:+.1%}, {hi:+.1%}]")
    print("含 0 吗:", "含，不能下结论" if lo < 0 < hi else "不含，差异大概率真实")

    a = [1] * 12 + [0] * 8
    b = [1] * 9 + [0] * 11
    d2, lo2, hi2 = ci_bootstrap(a, b)
    print(f"自助法: 差={d2:+.1%}, 95% CI=[{lo2:+.1%}, {hi2:+.1%}]")
```

**验收**：两个方法给出的区间应当接近（自助法每次略有浮动，正常）。n=20 时区间大概在 ±35pp 量级——你会直观感到 **20 次根本不够下结论**，这正是要的感觉。

> 小样本提醒：通过率很低（如 <5/20）时 Wald 公式会失真，自助法更稳。报告里两种都算、结果一致才放心——这本身就是"答案可信度"意识。

## 5. 三个最容易犯的误读（面试常考）

1. **"CI 含 0 = 两组没差异"** ❌。正确说法：**这次实验没有提供可区分的证据**。也许真有差异，样本不够而已。（对照你 mini 项目复盘里那句"全部通过不代表完美"——同一族陷阱。）
2. **"点估计大就显著"** ❌。5pp 的差异在 n=20 时毫无意义，在 n=2000 时可能很扎实。**看差异先问样本量。**
3. **"区间宽 = 实验失败"** ❌。宽区间是诚实的结果，写进报告并给"下一步加样本"的建议，比硬编一个结论值钱得多——JD 原话："分不清就仅观察，比硬编一个结论有价值得多"。

## 6. 报告里的标准句式（直接抄）

- 显著：*"截断组通过率 37.5%，对照组 62.5%，差 25.0pp，95% CI [8.3pp, 41.7pp]，不含 0——差异大概率真实。"*
- 不显著：*"两组差 5pp，但 95% CI [-4.7pp, +14.7pp] 含 0，未发现可区分的证据；如需进一步判断，建议每配置样本增至 N=200。"*
