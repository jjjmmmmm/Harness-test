## 翻译格式说明（为什么是 Markdown）

- **论文**：中文精读用 `.md`（VS Code / Typora 直接打开，表格和代码块渲染清晰，可搜索、可批注）；**PDF 原文保留在同目录**——论文里的图表（尤其 Harness-Bench 的失败分类表）以 PDF 为准，引用数字前回 PDF 核对。
- **DSH 文档**：仓库自带**官方中文版**（比机翻可靠），已下载到 `DSH/原文/`；所以我没有重复翻译，而是写了**零基础详解**——先用人话给你讲懂概念，再带着概念去读官方中文版。
- 所有翻译是**参考译本**；面试引用具体数字/表述前，以原文为准。

## 使用纪律（和计划里的三条一脉相承）

1. **详解/教程是导航不是替身**：代码要手敲，论文笔记要自己写——AI（我）讲概念、审代码、反驳设计，但判断必须是你的。
2. **数字回原文核对**：面试引用论文数字前，回 PDF 确认一遍。
3. **卡壳 30 分钟规则**：任何资料看不懂的地方，标记后先跳过，当晚集中清；教程末尾的自测题答不出来才算没过。
