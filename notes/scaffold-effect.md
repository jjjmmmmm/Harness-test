# Scaffold Effect 精读笔记（v4 版材料）

日期：2026-09-21｜Block：D1-1｜两问为**闭卷打字作答**，原样收录

**一句话主张**：Sentient Labs 固定任务与模型、只换 harness 做 300 次受控试验——通过率分不清（0–8pp，CI 含 0），成本与失败形态分得清（40×、指纹跨模型复现），建议以 **harness–模型对**为评测单位，并报 token / 空转轮 / 失败类别向量。

**设计网格**：3 个 harness（Goose、OpenCode、OpenHands-SDK）× 2 个模型（Qwen 3.6 Plus、MiniMax M2.5）× 50 题（Terminal-Bench Pro 分层抽样）= 300 次试验，每格 1 次运行。
**不确定性方法**：95% 配对任务自助（B=10,000）——对"题"重抽样，任务难度被配对抵消；不是重复运行。

**控制底线（固定）**：原题指令逐字、原生 pytest、同 Daytona 沙箱、900 秒墙钟、同 OpenRouter 网关、系统提示词几乎完全一致。
**故意不固定（研究对象本身）**：原生工具 API、自动上下文预载（Goose 预载文件树）、内部重试/子 agent 逻辑；暴露的预算控制（OpenCode 无 40 轮上限）也不拉平。

**四个发现**：
1. 通过率：模型内 harness 极差 2–8pp，CI 除最大差距外均含 0 → 只能说"无法区分"；
2. token：每解一题差 40×（Goose 28K vs OpenCode 1.15M），CI 完全不重叠 → 稳健；差距来自每轮上下文膨胀不是轮数（轮数只差 1.2×）；
3. 失败指纹跨模型复现：Goose=REASON（认输型）、OH-SDK=VERIFY+MAX TURNS（假完成型）、OpenCode=TIME+空转 → **脚手架属性，非模型属性**；
4. 无动作轮次：OpenCode 2.0–2.16 vs Goose 0.2–0.3 = 10×，每轮带全量上下文 → "空转税"。

**它自己报的不确定性**（📕 已核）：Table 2 通过率 CI（Goose@MiniMax 38.0% [24.0, 52.0]）＋ Table 3 token CI（Goose@Qwen 28,142 vs OpenCode@Qwen 1,147,740 = 40.8×）。
**它建议别人报的**：harness–模型对为单位 / 每解一题 token / 平均无动作轮次 / 失败类别向量。
**最大的洞**：n=50 只算描述性；只换整 harness、未拆单个零件。（补两条轻的：token 计账不对称——Goose 无输入/输出拆分；轮预算不对称 + 3×2 外推需谨慎。）
**挑刺记录**：摘要说"CI 含 0，除最大差距外"，但正文该差距 CI = [-18.0, **0.0**] 恰好触 0——触 0 算不算"不含 0"，论文自己留了边界含糊。

## 两问答案（闭卷作答，2026-09-21 原文收录）

**Q1：它怎么论证"差异不能干净地归因给模型"？**
① 两条腿：固定模型换 harness＋固定 harness 换模型，双向对照。
② 量级：通过率 0–8pp vs 4–10pp（都在噪声内）；成本 40× vs 1.0–1.3×、空转轮 10× vs <1.1×（harness 碾压）。
③ 排名：失败指纹换模型不翻转 → 打掉"画像跟模型走"的解释。
④ 口径：CI 含 0 = 测不出 ≠ 不存在 → 只说"无法归因"，把确定性放在成本侧。

**Q2：它的证据链长什么样？**
① 网格：3 harness × 2 模型 × 50 题 = 300 次，每格 1 次；不确定性靠对题配对自助（B=10,000），非重复运行。
② 任务与指标：TB-Pro 分层 50 题；主 = 通过率 + 每解一题 token，辅 = 空转轮 + 六类失败向量。
③ 固定 vs 不固定：固定指令/测试/沙箱/900 秒/网关/提示词；故意不固定工具 API、预载、重试逻辑——研究对象本身。
④ 不确定性：通过率 CI 宽 28pp（📕：38.0% [24.0, 52.0]）；token CI 不重叠（📕：28,142 vs 1,147,740 = 40.8×）。
⑤ 缺口：n=50 只算描述性；只换整 harness、没拆到单个零件。
