## 唯一要会的公式（两比例之差的 95% CI）

```
p1 = x/n,  p2 = y/n,  diff = p1 - p2
SE = sqrt( p1(1-p1)/n + p2(1-p2)/n )    # 差异的"典型抖动量"
95% CI ≈ diff ± 1.96 × SE               # 1.96 ≈ 正态中间 95%，记 ≈2 就行
```

判读三条（背下来）：

| 情形 | 结论 |
| :--- | :--- |
| 不含 0 | 差异大概率是真的 → 可以说"A 更好"（附区间） |
| **含 0** | 只能说"**未发现可区分的证据**" |
| 太宽 | 不是没差异，是**样本太少** → 加样本重跑，不硬下结论 |

## 解 JD 那句话："0–8pp 且 CI 含 0"

例算（教程 §3，n=200×2，A 60% vs B 55%）：diff=5pp，SE≈0.0494，CI = [-4.7pp, +14.7pp] **横跨 0**——点估计 +5pp 也**不能**说 B 更差，运气完全可能造出这 5pp。
自己的话：**"光看跑分分不清" = 差异与噪声同量级，区间盖住 0，这份数据无力区分两个配置。**对照 Scaffold Effect：通过率差 0–8pp（CI 含 0，分不清），token 差 40×（CI 不重叠，分得清）——分数分不清的，代价分得清。

## 三个误读 → 三种正确说法（D2 验收 5；D1 我踩过第 1 个）

1. ❌"CI 含 0 = 两组一样/没差异" → ✅"**这次实验没有提供可区分的证据**"——也许真有差异，只是样本不够。（D1 命门问答我把含 0 读成"一样"，正确读法是"**无法区分**"，这条必须复测过关。）
2. ❌"点估计大就显著" → ✅"看差异**先问样本量**"——5pp 在 n=20 毫无意义，n=2000 可能扎实。
3. ❌"区间宽 = 实验失败" → ✅"宽区间是**诚实的结果**"——如实报区间 + 承认证据不足 + 给加样本建议（JD 原话："分不清就仅观察，比硬编一个结论有价值得多"）。
